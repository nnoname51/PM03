# 🛒 Система учета и моделирования заказов интернет-магазина

Десктопное приложение на Python для учета заказов, симуляции нагрузки на склад и анализа ключевых финансовых показателей интернет-магазина. Проект разработан с использованием стандартной библиотеки `tkinter` и базы данных `SQLite`, поэтому работает «из коробки» без установки сторонних пакетов.

---

## ✨ Возможности и версии проекта

В репозитории представлены две версии программы, демонстрирующие развитие функционала от базового прототипа до полноценной системы аналитики:

### 🔹 Версия 1.0 (`v1_basic.py`) — Базовая
* **Имитационное моделирование:** Генерация случайного потока заказов за заданное количество дней с учетом разброса количества товаров, стоимости и времени сборки на складе.
* **Хранение данных:** Автоматическое сохранение сгенерированных заказов в локальную базу данных `SQLite`.
* **Дашборд с метриками:** Расчет и вывод основных показателей в виде карточек (общее число заказов, выручка, средний чек, среднее и максимальное время сборки).
* **Журнал заказов:** Отображение последних записей из базы данных в удобной таблице.

### 🚀 Версия 2.0 Pro (`v2_advanced.py`) — Расширенная
Включает весь функционал первой версии, а также:
* **Управление заказами (CRUD):** Возможность вручную добавлять новые заказы в базу и удалять выбранные записи прямо из интерфейса.
* **Фильтрация по дням:** Быстрый отбор заказов за конкретный день работы магазина.
* **Визуализация данных:** Встроенная вкладка со столбчатым графиком динамики ежедневной выручки (отрисовка на `Canvas` без использования тяжелых библиотек).
* **Экспорт отчетности:** Выгрузка всей базы заказов в файл формата `.csv` с правильной кодировкой для мгновенного открытия в Microsoft Excel.

## 🛠 Технологический стек

* **Язык программирования:** Python 3.x
* **Графический интерфейс (GUI):** Tkinter / ttk (современная темная тема)
* **База данных:** SQLite3
* **Экспорт данных:** Модуль `csv`

## 🚀 Установка и запуск

Приложение не требует установки внешних зависимостей через `pip`.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd название-репозитория
   ```

2. **Запустите нужную версию программы:**
   * Для запуска базовой версии:
     ```bash
     python v1_basic.py
     ```
   * Для запуска расширенной версии:
     ```bash
     python v2_advanced.py
     ```

## 📊 Как работает математическая модель

При запуске симуляции система моделирует работу магазина по следующим правилам:
1. **Поток заказов:** Ежедневно генерируется случайное количество заказов в диапазоне `±10` от заданного среднего значения.
2. **Состав и чек:** В каждом заказе от `1` до `10` позиций, стоимость каждой единицы товара варьируется от `500` до `2500` рублей.
3. **Нагрузка на склад:** Время сборки рассчитывается как базовое время на каждый товар (`1.5 мин/шт.`) плюс случайная экспоненциальная задержка.
